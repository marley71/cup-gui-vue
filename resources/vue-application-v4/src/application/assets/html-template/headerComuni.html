Questo esempio mostra come passare un file html da sostituire alla descrizione.
Il file deve essere messo nella cartella definita dalla variabile di configurazione VITE_PUBLISH_DIR
Questo modo di aggiungere html dinamico in una form, o pagina custom e' utlizzabile ovuque, utilizzando la funzione del core fetchHtml('nomefile.html',callback(htmlContenuto),templateData)
L'importazione si aspetta un file excel con i seguenti campi:
(GTComIstat, per esempio 12939)
(GTComDes, per esempio Pontedera)
(GTComPrv, per esempio Pisa)
(GTComCod, per esempio A074)
Attenzione, il programma tiene conto delle maiuscole e minuscole. Scrivere le intestazioni delle colonne excel come evidenziato in grassetto.
Valore dinamico di una variabile passato dalla configurazione o elaborato dinamicamente che vogliamo mostrare in descrizione {{nome}}
